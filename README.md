# Sistem Informasi Perpustakaan (app-perpustakaan)

Aplikasi web pengelolaan perpustakaan kampus berbasis Laravel 12.

## Konsep MVC
- **Model**: Mengelola interaksi data dan aturan database.
- **View**: Menangani tampilan antarmuka (UI) menggunakan Blade template.
- **Controller**: Logika utama yang menghubungkan request pengguna dengan Model dan View.
